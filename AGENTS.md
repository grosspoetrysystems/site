# grosspoetry.systems

Studio site for Gross Poetry Systems. TanStack Start on a Cloudflare Worker, with Writing (`writing/`, Astro) built into `public/writing/` and shipped in the same deploy.

## Commands

- `pnpm install`
- `pnpm dev`: site at http://localhost:4180 (tokens rebuilt first)
- `pnpm writing`: Writing on its own dev server
- `pnpm check`: lint, typecheck (site and Writing), tests, Knip. Must pass before any commit.
- `pnpm build`: Writing, then the site, prerendering `/` and Writing
- `pnpm deploy`: only with the owner's go-ahead

## Where things live

- Catalogue data: `src/lib/catalogue.ts`
- Title, description, canonical and share card for every path: `src/lib/share.ts`
- Agent surfaces (`llms.txt`, `catalogue.json`, sitemap, JSON-LD): `src/lib/agents.ts`, `src/routes/`, `public/openapi.json`, `public/robots.txt`
- Design tokens: `tokens/gps.tokens.json`. `src/tokens.css` is generated by `pnpm tokens`; don't edit it.
- Writing pieces: `writing/src/posts/*.md`. The filename is the URL.

## Rules

- GPS is an organisation. Never put a person's name in content, metadata or structured data.
- Style with tokens and Tailwind utilities; `@shadcn/lint` rejects arbitrary values and inline styles.
- Copy comes from the owner. Don't write marketing prose, taglines or descriptions.
- External docs and source links use `ExternalLink` (new tab, marked visually and for screen readers).
- `robots.txt` blocks AI training crawlers on purpose; don't relax it to raise a score.
- Commits follow Conventional Commits (commitlint) and are authored as the org.
